# NEON RIFT

Неоновая браузерная аркада на выживание. Один пилот, десять волн и разлом, который нужно закрыть.

## Играть

Двигайся по арене, уклоняйся от врагов и собирай зелёную энергию. Корабль автоматически стреляет в ближайшую цель. Между волнами выбирай один из трёх случайных модулей. На пятой и десятой волнах появляются боссы.

| Действие                       | Управление                               |
| ------------------------------ | ---------------------------------------- |
| Движение                       | WASD или стрелки                         |
| Рывок с короткой неуязвимостью | Пробел                                   |
| Пауза                          | P или Escape                             |
| Начать игру                    | Enter или кнопка                         |
| Телефон / планшет              | Веди пальцем по арене; кнопка ⚡ — рывок |

Быстрые убийства повышают комбо до ×5. Энергия поддерживает комбо. Получение урона сбрасывает множитель. Каждая пройденная волна восстанавливает одну единицу щита; модуль «Новый щит» восстанавливает его полностью. Рекорд сохраняется только в текущем браузере. При потере фокуса игра автоматически ставится на паузу.

## Запуск

Требуются Node.js 22.13+ и pnpm.

```sh
pnpm install --ignore-scripts
pnpm dev
```

```sh
pnpm test
pnpm typecheck
pnpm build
```

Сборка создаёт статический сайт в `dist/client/`. Его можно разместить на статическом хостинге в корне домена. Локально готовую сборку можно открыть через `python -m http.server 8080 --directory dist/client`.

## Устройство проекта

- `lib/game.ts` — независимый игровой движок: волны, столкновения, оружие, боссы, улучшения.
- `lib/render.ts` — отрисовка Canvas 2D и частицы.
- `app/game-screen.tsx` — интерфейс, клавиатура, сенсорное управление, звук и рекорд.
- `tests/game.test.mjs` — тесты боевой логики и полного прохождения десяти волн.

TypeScript, React, Canvas 2D, Web Audio, Vite/Vinext. Игровая графика процедурная; внешние изображения, сервер, аккаунты и API-ключи для игры не нужны. Звук можно отключить в правом верхнем углу.
