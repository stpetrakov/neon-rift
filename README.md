# NEON RIFT

Неоновая браузерная аркада на выживание. Один пилот, десять волн и разлом, который нужно закрыть.

## Играть

[Открыть игру](https://neon-rift-stpetrakov.stpetrakov957678.chatgpt.site) — доступна всем по ссылке, без входа в аккаунт.

Кнопка ⛶ справа вверху включает полноэкранный режим; повторное нажатие или Escape возвращает обычный вид. Если браузер не поддерживает полный экран, игра разворачивается на всю вкладку.

Версия 2: прицеливайся и стреляй вручную, меняй оружие, управляй нагревом и собирай энергию для защитного импульса. Между волнами выбирай один из трёх случайных модулей из восьми доступных типов. На пятой и десятой волнах появляются боссы.

Перед стартом выбери сложность и настрой перегрев в блоке «Настрой заход». Выбор сохраняется в браузере и применяется к новому заходу. После поражения или победы можно изменить настройки; из паузы кнопка «Новый заход с другими настройками» завершает текущую попытку и возвращает к выбору.

| Сложность | Щит на старте | Врагов за 10 волн | Особенности                                               |
| --------- | ------------- | ----------------- | --------------------------------------------------------- |
| Лёгкая    | 6             | 275               | Враги слабее и медленнее, предупреждения об атаках дольше |
| Обычная   | 4             | 360               | Прежний баланс версии 2                                   |
| Сложная   | 3             | 455               | Враги крепче, быстрее двигаются и чаще атакуют            |

Перегрев настраивается независимо от сложности: **стандартный**, **выключен** или **вручную**. В ручном режиме отдельно регулируются скорость нагрева и охлаждения — от 25% до 200% с шагом 25%. Значение 100% сохраняет прежнюю скорость. При отключении перегрева оба оружия не нагреваются, а бесполезный в этом режиме модуль охлаждения не предлагается. Зарядка рельсотрона остаётся. Рекорды раздельные для каждой сложности и комбинации параметров; прежний рекорд доступен в обычном режиме со стандартным перегревом.

| Действие                       | Управление                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| Движение                       | WASD или стрелки                                                                                |
| Прицел                         | Мышь                                                                                            |
| Плазма                         | Удерживай левую кнопку мыши                                                                     |
| Смена оружия                   | Q или кнопка под ареной                                                                         |
| Рельсотрон                     | Зажми огонь для заряда, отпусти для выстрела                                                    |
| Защитный импульс               | E, правая кнопка мыши или кнопка под ареной                                                     |
| Рывок с короткой неуязвимостью | Пробел                                                                                          |
| Пауза                          | P или Escape                                                                                    |
| Начать игру                    | Enter или кнопка                                                                                |
| Телефон / планшет              | Левый джойстик — движение; правый — прицел и огонь; кнопки под ареной — оружие, импульс и рывок |

Плазма удобна против групп, а заряженный рельсотрон пробивает несколько целей. При включённом перегреве оба оружия используют общий нагрев: при 100% стрельба блокируется до охлаждения до 25%. Делай паузы между очередями. На сенсорном экране отклони правый джойстик для огня; для выстрела из рельсотрона отпусти его после зарядки.

Импульс уничтожает ближайшие вражеские снаряды, наносит урон и отбрасывает обычных врагов. Он расходует 100% энергии; каждая собранная зелёная частица возвращает 10%. Частицы исчезают через 18 секунд активного боя.

У охотников, фланкеров и стрелков разные тактики. Со второй волны штурмовики готовят быстрый рывок, с третьей снайперы фиксируют прицел перед выстрелом и появляются опасные зоны разлома. Уходи с линий атак и из отмеченных кругов до окончания предупреждения. При низком здоровье боссы входят в ярость: стреляют чаще и добавляют прицельные залпы.

Волны не восстанавливают здоровье; модуль «Ремонт щита» добавляет одну к максимуму (до семи) и лечит на две. Быстрые убийства повышают комбо до ×5. Собранная энергия продлевает комбо, получение урона сбрасывает его. Рекорды хранятся в текущем браузере. При потере фокуса игра автоматически ставится на паузу.

## Запуск

Требуются Node.js 22.13+ и pnpm.

```sh
pnpm install --ignore-scripts
pnpm dev
```

```sh
pnpm test
pnpm typecheck
pnpm build
```

Сборка создаёт статический сайт в `dist/client/`. Его можно разместить на статическом хостинге в корне домена. Локально готовую сборку можно открыть через `python -m http.server 8080 --directory dist/client`.

## Устройство проекта

- `lib/game.ts` — независимый игровой движок: волны, столкновения, оружие, боссы, улучшения.
- `lib/render.ts` — отрисовка Canvas 2D и частицы.
- `app/game-screen.tsx` — интерфейс, клавиатура, сенсорное управление, звук и рекорд.
- `tests/game.test.mjs` — тесты боевой логики и полного прохождения десяти волн.

TypeScript, React, Canvas 2D, Web Audio, Vite/Vinext. Игровая графика процедурная; внешние изображения, сервер, аккаунты и API-ключи для игры не нужны. Звук можно отключить в правом верхнем углу.
